App Description (100-125 words)
Control Web Panel (CWP) is a free, open-source hosting control panel that turns a single
AlmaLinux server into a complete hosting platform. It installs and configures a web server
with Nginx, Apache and Varnish caching, multiple PHP versions, mail with Postfix and Dovecot,
DNS with BIND or PowerDNS, FTP, Let's Encrypt certificates, per-account backups, a cPanel
account migration tool and a REST API. Because the panel carries no licence fee at any scale,
a provider can sell the same hosting plan with a better margin than with cPanel. The one-click
deployment installs CWP unattended, opens the required firewall ports and hands the customer
a ready panel: no terminal work is needed after the Linode finishes booting.
