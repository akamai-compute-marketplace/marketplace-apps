## App Information

### App Name

OpenBroadcaster

### App description

OpenBroadcaster is open source radio and TV automation. This app installs OpenBroadcaster Server (OBServer), the web application where a station manages its media library, playlists and schedules. One server can drive one or many OpenBroadcaster players in sync, or run alongside playout on the same machine, and its documented API lets stations share media and metadata with revocable keys. Modules extend the core with features such as logging and now-playing data. The deployment configures nginx, PHP, MariaDB and a Let's Encrypt certificate, sets a generated password for the admin account, and runs OpenBroadcaster's own install check before it finishes, so the station starts from a working, secured server.
